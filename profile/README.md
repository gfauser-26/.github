## Le regole d'oro

1. **Salva spesso.** Su LiveCodes ogni **Salva** è un *commit*; dal computer `git commit` e `git push`. Quello che non salvi non esiste.
2. **Consegna prima della scadenza.** Vale l'ora in cui la consegna arriva su GitHub. Puoi consegnare più volte: vale l'ultima.
3. **Il codice è tuo.** L'AI aiuta a capire, non scrive l'esercizio al posto tuo: scrivi come l'hai usata. Devi saper spiegare il tuo codice **riga per riga**.
4. **Niente dati personali.** Mai password, token, nomi o email nei file e nei commit.
